# NetIntel AI Suite

Three machine learning components for network operations: anomaly detection on traffic logs, alert correlation, and reinforcement learning for SD-WAN path selection. A Streamlit dashboard sits over all three.

[![Python](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## Components

### 1. Anomaly detection

An LSTM autoencoder trained on normal traffic, flagging sequences it cannot reconstruct. Unsupervised, so no labelled attack data is needed.

| Path | Contents |
| --- | --- |
| `project1_anomaly_detection/models/lstm_autoencoder.py` | Model definition and training |
| `project1_anomaly_detection/api/app.py` | Inference API |
| `project1_anomaly_detection/data/synthetic_network_logs.py` | Traffic generator used for training and evaluation |
| `project1_anomaly_detection/tests/test_model.py` | Model tests |
| `project1_anomaly_detection/deployment/Dockerfile` | Container image |

### 2. Alert correlation

Groups related alerts into single incidents so an operator sees one event instead of forty. Implemented in `project2_alert_correlation/engine/correlation_engine.py`.

### 3. SD-WAN path optimiser

A Deep Q-Network agent that learns path selection under changing link conditions, trained against a simulated network environment.

| Path | Contents |
| --- | --- |
| `project3_sdwan_optimizer/agents/dqn_agent.py` | DQN agent |
| `project3_sdwan_optimizer/simulator/network_env.py` | Environment the agent trains against |

## Data

Training and evaluation use synthetic traffic generated by `project1_anomaly_detection/data/synthetic_network_logs.py`. The sample sets committed at the repository root, `training_data_clean.csv` and `test_data_with_anomalies.csv`, come from that generator. Any figures produced by the components describe behaviour on this synthetic data.

## Quick start

```bash
git clone https://github.com/MarckMorris/netintel-ai-suite.git
cd netintel-ai-suite

pip install -r requirements.txt
./run_demo.sh
```

Or bring the whole stack up in containers:

```bash
docker compose up -d
```

The Streamlit dashboard is at `http://localhost:8501`.
